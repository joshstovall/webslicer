CAD converter licenses and source

Stratum uses occt-import-js 0.0.23 by Viktor Kovacs and Open CASCADE Technology. The converter is loaded on demand in a separate browser worker. Model files stay in your browser.

The library binaries are taken unchanged from the pinned npm package; Vite bundles its JavaScript adapter. Library source has not been modified. All copyright notices remain in the source archives and license files. The library is supplied without warranty; see its licenses.

Build and replace the converter

Extract the wrapper archive, then extract the Open CASCADE archive into its occt/ directory (remove the archive's leading directory). The wrapper includes its CMakeLists.txt and tools/ build scripts. Upstream uses Emscripten 3.1.69; follow those scripts to rebuild dist/occt-import-js.js and dist/occt-import-js.wasm.

Clone the Stratum source, run npm ci, replace these two files under node_modules/occt-import-js/dist/, then run VITE_BASE_PATH=/webslicer/ npm run build. Serve the complete dist folder to use your modified converter. There are no signature or activation checks. Modification and reverse engineering for debugging modifications to the LGPL libraries are permitted.
